# Bank-Customer-Churn-Analysis
Interactive Power BI dashboard analyzing bank customer churn across geography, age group, gender, salary, and activity status to uncover churn patterns and support data-driven customer retention strategies.

📊 Project Overview:

- This project analyzes bank customer churn behavior using an interactive Power BI dashboard.
- The dashboard helps identify patterns in customer churn based on age group, geography, gender, salary group, and activity status.

📁 Dataset :

The dataset contains customer information including:
- Customer demographics
- Geography
- Age group
- Gender
- Salary group
- Activity status
- Customer churn status

🛠 Tools Used :

- Power BI
- DAX
- Data Visualization
- Data Modeling

📌 Dashboard Features :

- Total Customers KPI
- Churned Customers KPI
- Churn Rate %
- Churn by Geography
- Churn by Age Group
- Churn by Salary Group
- Churn by Gender
- Customer Activity Status Analysis
- Interactive Filters (Geography, Salary Group, Activity Status)

🔍 Key Insights :

- Total customers: 10K
- Churned customers: 2037
- Churn rate: ~20%
- Germany and France show higher churn compared to Spain
- Customers aged 46–55 have the highest churn rate
- Inactive customers churn significantly more than active customers
